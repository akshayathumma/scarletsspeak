The project, Scarletsspeak, is a full-stack, anonymous story-sharing platform built with Node.js and Express that functions as a non-medical period blog, offering users a safe space to share personal experiences without clinical terminology. It utilizes a RESTful API to manage user stories, employing the POST /stories endpoint for submission and GET /stories for retrieval from a MySQL database. All stories are stored with a timestamp, and authors default to "Anonymous," promoting a focus on the narrative content itself. The application ensures secure configuration using dotenv to externalize credentials and serves its frontend (HTML, CSS, JS) statically from the public directory, providing a cohesive and user-friendly experience.
